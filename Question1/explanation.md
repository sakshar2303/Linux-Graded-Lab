# Question 1 - Command Explanations

## mkdir Linux-Graded-Lab
Creates the main project directory for the assignment.

## cd Linux-Graded-Lab
Moves into the project directory.

## mkdir Question1
Creates a separate folder for Question 1.

## mkdir submissions backup screenshots
Creates directories to store student submissions, backup files, and screenshots.

## ls
Lists the files and directories in the current folder to verify they were created.

## echo "Operating Systems Assignment" > student1.txt
Creates a sample student submission.

## cp student1.txt student2.txt
Creates a duplicate submission for testing duplicate detection.

## echo "Linux Lab Assignment" > student3.txt
Creates another unique submission.

## nano duplicate_backup.sh
Creates the shell script.

## chmod +x duplicate_backup.sh
Makes the shell script executable.

## ./duplicate_backup.sh
Executes the script to detect duplicates, back up unique files, and generate reports.

## ls backup
Displays the files that were successfully backed up.

## cat report.txt
Shows the summary report generated by the script.

## cat errors.log
Displays any errors generated during execution. The file is empty because no errors occurred.

# Question 1

## Objective

This shell script identifies duplicate student submissions using file hashes, creates a backup of unique files, generates a processing report, and stores all error messages in a separate log file.

## Files

- duplicate_backup.sh
- report.txt
- errors.log
- explanation.md
- submissions/
- backup/
- screenshots/

## Linux Commands Used

- mkdir
- cd
- ls
- cp
- md5
- chmod
- cat
- redirection operators (>, >>, 2>)
